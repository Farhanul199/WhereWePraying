Go live

Leave on "All countries" to do the lot.

Step 1 — look first (optional)

Preview shows what the next 50 would do — new listing, or linked to one already live. Changes nothing. "Find coordinates" is only for sources whose mosques have an address but no map location; they can't go live without it.

Step 2 — put them on the site

The main button. Puts every ready mosque from this tab on the live site and gets their prayer times ready to read. Takes a few minutes for a big source — leave the tab open.

Step 3 — check it worked

Asks the live site what a visitor at your location would see right now: how many mosques, and how many have times today.

Progress by source

Fixing things

Promote all ready — the first half of Step 2 on its own (listings, no times).
Prepare prayer times — the second half on its own, across every source.
Prepare a batch now — readies one small batch; normally happens by itself twice a day.
Undo last batch — removes only the mosques the last run added to this source.
Set old mosques aside — hides everything that didn't come from this page. Reversible.

Duplicate mosques

Finds live mosques listed twice (same spot, or same name within 400m). Merging combines them into one definitive entry: the one with prayer times is kept, any gaps it has (address, postcode, coordinates, website) are filled from the other, and the other's times, source links, photos and favourites move across. The other entry is hidden, not deleted. Untick anything that isn't really the same mosque.

Pressing a go-live button is your sign-off. Each mosque is either added as a new listing, or linked to a live mosque it duplicates (same spot, or same name + postcode) so its times attach there instead. Each mosque serves its own stored timetable — nothing is copied per day, and any area a visitor opens gets itself ready automatically. New listings appear as each area refreshes, within the hour.

Masjidal has no "list all mosques" API — IDs only show up as widget embeds on a mosque's own site. Paste in mosque website URLs and this fetches each page and scans it for one. No mosque name/address comes back from Masjidal itself, so these rows stay unnamed until matched to a mosque record separately.

One JSON object per line — name, street, postcode, city, phone, website, email. Address only, no coordinates and no prayer times — re-upload a newer export any time to refresh.

Or find mosques by continent

Runs "Find mosques" for every country in that continent, one after another — your own site allows 10 admin requests a minute, so each country takes about 7 seconds. Small ones (Oceania, South America) finish in under 2 minutes; Africa/Europe/Asia take 5–6 minutes; "every country" takes about 20 minutes. Keep the tab open and active (don't switch away on mobile — background tabs can pause the timer).
